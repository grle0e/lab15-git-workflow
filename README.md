# Энгийн Java Тооцоолуур Төсөл

Энэ бол Лаб 15-д зориулж үүсгэсэн Maven суурьтай Java тооцоолуур төсөл юм. Энэ төсөл Git workflow ба GitHub Actions-ийг ашиглан тасралтгүй интеграцийг хэрхэн хийхийг харуулна.

## Төслийн бүтэц

- Эх код: `src/main/java/lab15/sict/must/edu/mn/`
- Тест файлууд: `src/test/java/lab15/sict/must/edu/mn/`
- Maven тохиргоо: `pom.xml`
- Кодын загвар тохиргоо: `checkstyle.xml`

## Боломжууд

Тооцоолуур одоогоор дараах үйлдлүүдийг агуулж байна:
- Нэмэх
- Хасах
- Үржүүлэх
- Хуваах (тэгээр хуваахыг зөв зохицуулсан)
